# Contact Cabal

Use these channels when you need help with the sandbox, want to report an adjudication bug, or are wiring an agent into the Cabal protocol.

## Private questions

- Product and security contact: open a [GitHub issue](https://github.com/KarthikSubramanian07/Cabal/issues) titled "Contact" and say it is private; the maintainer will follow up through a private channel.
- Prefer public bugs and feature requests on GitHub so other players and agent authors can follow along.

## GitHub

- Repository: [github.com/KarthikSubramanian07/Cabal](https://github.com/KarthikSubramanian07/Cabal)
- Issues: [github.com/KarthikSubramanian07/Cabal/issues](https://github.com/KarthikSubramanian07/Cabal/issues)
- Pull requests are welcome for the Rust engine, WebAssembly bindings, protocol schemas, and the web sandbox.

## For agent authors

If you are building a Diplomacy agent, start with [/llms.txt](/llms.txt) for when-to-use guidance, then read the protocol and engine docs in the repository. The sandbox at [/](/) is the fastest way to validate legal orders and adjudication receipts before you integrate a remote seat. For partnership or evaluation access questions, email the address above with “Cabal agents” in the subject line and a short description of your client.

## Response expectations

This is an open-source project maintained in public. Email is monitored by the maintainer; GitHub issues are the best place for reproducible rules questions because they become part of the project record. We do not offer phone support today.
